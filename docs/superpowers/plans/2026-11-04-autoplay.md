# Autoplay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a map from the game's export folder with a synthetic, dancing cursor, marked three ways as an Autoplay video, with a checker in `rhythr-cli` that finds the hidden mark.

**Architecture:** A new `autoplay` module in the render crate turns a `Map` plus settings into an in-memory `Replay` (frames with hit flags) that the existing pipeline renders unchanged. A new `mark` module holds the key seed, the pattern, the GPU compositor pass that adds it to every Autoplay frame, and the checker maths; `rhythr-cli` gets `autoplay` and `mark-check`, the GUI gets the picker, the Autoplay card and tab, and the plumbing that hides what must not exist for Autoplay (results screen, score card, Analyze, ghost).

**Tech Stack:** Rust 2021 workspace (crates `rhythia-formats`, `rhythia-sim`, `rhythia-render`, `rhythia-cli`, `rhythia-gui`, `rhythia-errcode`), wgpu 30, Tauri 2 with a plain HTML/JS front end, ffmpeg over pipes, `rustfft` (new dependency, MIT/Apache) for the checker, `sha2` as a build dependency of the render crate.

**Spec:** `docs/superpowers/specs/2026-11-03-autoplay-design.md`

## Global Constraints

- No code path serialises a `Replay`; `rhythia_formats` keeps having no `.rhr` writer. The synthetic run exists only as a value in memory.
- UI text in English. No em or en dashes anywhere in the repository (`scripts/preflight.sh` fails on them). The name of the other rhythm game the reference videos came from never appears in the repository.
- Every new command appears in `docs/USER-GUIDE.md`; every new error code in `crates/errcode/src/lib.rs` has a row in `docs/ERROR-CODES.md` (`RHYTHR_UPDATE_DOCS=1 cargo test -p rhythia-errcode`) and a non-empty `fix` ending with a full stop.
- The ticker and the hidden mark have no setting, no config key and no flag that turns them off.
- Mark parameters are the spike's: pattern grid 640 by 360, band-pass gaussian sigma 1 minus sigma 3, zero mean, unit variance, amplitude 0.8 of 255 added to every colour channel; Autoplay renders clear to RGB 1/255 so the pattern keeps its negative half. The checker's verdict: found when z is above 10, weak between 6 and 10, no mark below 6.
- Speed mod range 0.80 to 2.00 in steps of 0.05 (CLI and GUI). Rest threshold 2.0 to 8.0 s, default 4.5 s. Dance amount scales subtle 0.5, medium 1.0, wild 1.5.
- Pure black in limited-range H.264 is luma 16; the checker never assumes 0.
- Commit messages end with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. One cargo process at a time. `node --check`, never `node -e require()`.
- Nothing is pushed and nothing is released: the deliverable is a test build in `~/RhythiaRenderer/` for the owner.

## Review Focus

1. Maps with notes outside the 3 by 3 grid (coordinates beyond 0..2) and notes exactly on the edge: the cursor must reach the note inside the barrier the way hitreg widens its own bound. Test pinned to Task 5 (`off_grid_notes_are_reached_and_clamped`).
2. Clusters of many notes at one millisecond (a chord of eight): every note registers through `match_hits` and no flag is orphaned. Test pinned to Task 5 (`a_chord_of_eight_registers_every_note`).
3. A `.rhm` without an `audio` entry: the render goes on silent with a warning code, not an error. Test pinned to Task 9 (`a_map_without_audio_renders_silent_with_a_warning`).
4. Vertical output (1080 by 1920) with the mark: the pattern is stretched to the frame and the checker stretches it back; a vertical synthetic clip must be found. Test pinned to Task 3 (`a_vertical_frame_is_found`).
5. A speed mod of 2.00 with the rest threshold: gaps are measured in real seconds, so a 9 s map gap at 2.00x (4.5 s real) is exactly the threshold and rests; the same gap at 1.00x rests too; a 6 s gap at 2.00x does not. Test pinned to Task 5 (`rest_threshold_is_real_time`).

Rulings taken from the recon, binding for every task:
- There is no `Scene` type; the barrier is `SceneParams::clamp_cursor` and the bound is `grid_scale + (0.5 - CURSOR_EDGE_INSET)`. The generator uses its own copy of that formula widened like hitreg's private `cursor_bound` (grid = max of 1.0 and every |world coordinate| of the notes).
- Hits register from `Frame.hit` flags only, one flag per note, in chart order, within plus or minus `hit_window_ms(replay)` of the note (55 ms times the replay's `speed`). The cursor position never registers a hit by itself; the generator places the cursor on the note anyway.
- A wgpu Unorm target clamps fragment output to [0, 1] before blending, so the mark needs two draws: one with `BlendOperation::Add` carrying the positive half, one with `BlendOperation::ReverseSubtract` carrying the negative half.
- RGB 1/255 converts to luma 17 (BT.601 limited); black in Autoplay renders is 17 and the checker does not care.
- `VideoOptions` has no resolution field; the renderer's dimensions decide. The spec's "speed" is `output_speed`; the speed mod is `Replay.speed`.
- `render_video` applies `map_for_replay`, `apply_mods` and `apply_speed(replay.speed)` itself; callers pass raw params and the raw map.
- The ticker is appended to `extra_hud` after the viewport shift in `submit_side` (renderer.rs, after the `verts.extend_from_slice(extra_hud)` line), outside every HUD toggle and `disable_gui`.
- The main-window toolbar `#preview-tools` is hidden until a preview exists; the Autoplay button lives in its own always-visible span before it.
- The kit browser harness cannot drive `index.html`; the front end is covered by Rust tests of the commands plus the owner's test round.
- `CHANGELOG.md` has no `## Unreleased` heading; Task 11 adds it.

#[test]
fn the_pattern_is_deterministic_zero_mean_unit_variance() {
    let s = seed_from_hex(DEV_KEY_HEX).unwrap();
    let a = pattern(&s);
    let b = pattern(&s);
    assert_eq!(a.len(), PAT_W * PAT_H);
    assert_eq!(a, b);
    let mean = a.iter().sum::<f32>() / a.len() as f32;
    let var = a.iter().map(|v| (v - mean) * (v - mean)).sum::<f32>() / a.len() as f32;
    assert!(mean.abs() < 1e-3, "mean {mean}");
    assert!((var - 1.0).abs() < 0.02, "variance {var}");
}

#[test]
fn different_keys_give_uncorrelated_patterns() {
    let a = pattern(&seed_from_hex(DEV_KEY_HEX).unwrap());
    let b = pattern(&seed_from_hex(&"ab".repeat(32)).unwrap());
    let corr: f32 = a.iter().zip(&b).map(|(x, y)| x * y).sum::<f32>() / a.len() as f32;
    assert!(corr.abs() < 0.01, "correlation {corr}");
}

#[test]
fn the_pattern_is_band_passed() {
    // neighbouring texels correlate (the sigma 1 blur), texels 12 apart do not (the sigma 3 blur removed the slow part)
    let a = pattern(&seed_from_hex(DEV_KEY_HEX).unwrap());
    let near: f32 = (0..PAT_H).flat_map(|y| (0..PAT_W - 1).map(move |x| (y, x)))
        .map(|(y, x)| a[y * PAT_W + x] * a[y * PAT_W + x + 1]).sum::<f32>() / ((PAT_W - 1) * PAT_H) as f32;
    let far: f32 = (0..PAT_H).flat_map(|y| (0..PAT_W - 12).map(move |x| (y, x)))
        .map(|(y, x)| a[y * PAT_W + x] * a[y * PAT_W + x + 12]).sum::<f32>() / ((PAT_W - 12) * PAT_H) as f32;
    assert!(near > 0.5, "near {near}");
    assert!(far.abs() < 0.05, "far {far}");
}

#[test]
fn hex_keys_are_validated() {
    assert!(seed_from_hex("zz").is_err());
    assert!(seed_from_hex(&"0".repeat(63)).is_err());
    assert_eq!(seed_from_hex(&format!(" {} \n", "A".repeat(64))).unwrap(), seed_from_hex(&"a".repeat(64)).unwrap());
}

#[test]
fn halves_split_the_sign() {
    let h = pattern_halves(&[0.0, 2.0, -2.0, 9.0]);

`mark.wgsl`: a full-screen triangle vertex stage; fragment samples the `Rg8Unorm` texture at the fragment's normalised position and returns `vec4(c, c, c, 1.0)` with `c = half * 4.0 * amp / 255.0`, where `half` is R for the add pipeline and G for the subtract pipeline (one shader with a uniform selecting the channel, or two entry points). ### Task 3: The checker maths

**Files:**
- Create: `crates/render/src/mark/check.rs`, `crates/render/src/mark/fft.rs`
- Modify: `crates/render/src/mark/mod.rs` (`pub mod check; mod fft;`)
- Test: unit tests in `check.rs`

**Interfaces:**
- Produces:
  - `pub struct Accumulator { ... }` with `pub fn new(width: usize, height: usize, black: f32) -> Accumulator`, `pub fn push_luma(&mut self, y: &[u8])` (one frame's luma plane, row major `width * height`; every third pushed frame is used, the others are skipped cheaply), `pub fn frames_used(&self) -> usize`, `pub fn average(&self) -> Vec<f32>` (the high-passed canonical average, `PAT_H * PAT_W`, zero mean)
  - `pub struct Verdict { pub score: f32, pub scale: f32, pub angle_deg: f32, pub offset: (i32, i32), pub null_mean: f32, pub null_std: f32, pub null_n: usize, pub z: f32, pub wrong_keys_max: f32, pub kind: VerdictKind }`
  - `#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum VerdictKind { Found, Weak, None }`
  - `pub fn check(avg: &[f32], pattern: &[f32], wrong_keys: &[Vec<f32>]) -> Verdict`
  - `pub fn canonical(y: &[u8], width: usize, height: usize) -> Vec<f32>` (area average to `PAT_W` by `PAT_H`; exact block mean when the size is a multiple, bilinear otherwise)
  - in `fft.rs`: `pub fn xcorr_peak(img: &[f32], ih: usize, iw: usize, pat: &[f32], ph: usize, pw: usize) -> (f32, (i32, i32))` (normalised cross-correlation over all offsets, local energy floored at a tenth of the image energy, offsets with less than 60 percent overlap ignored; padded size `(ih + ph, iw + pw)` rounded up to a `rustfft`-friendly size)

The search is the spike's three passes: coarse scales 0.7 to 1.4 in steps of 0.05 and angles minus 2 to 2 in steps of 0.5; medium around the best (scale plus or minus 0.05 in steps of 0.0125, angle plus or minus 0.5 in steps of 0.25); fine (scale plus or minus 0.0125 in steps of 0.005, angle plus or minus 0.25 in steps of 0.1). Scale means resampling the pattern (bilinear), rotation means rotating the average image about its centre (bilinear, zero fill). The null is the set of coarse peaks with 0.85 <= scale <= 1.15 that lie farther than 0.03 in scale or 0.5 degrees in angle from the best; when fewer than 20 exist, all coarse peaks farther than 0.1 in scale or 0.5 degrees. `z = (score - null_mean) / null_std`. `wrong_keys_max` is the best coarse score over the given wrong-key patterns at scales 0.7 to 1.4 step 0.1 and angles minus 1, 0, 1.

The replay value: `version` = the newest version constant in `rhythia_formats::rhr` (the one with pitch lock), `timestamp_ticks` from the system clock, `player_name` `PLAYER_NAME`, `legacy_map_id` `map.meta.legacy_id`, `map_id` `map.meta.online_id` clamped into i32 or 0, `start_from_ms` 0, `mode` `"autoplay"`, `passed` true, `mods` `"[]"`, `spin` false, `speed` the speed mod, `total_score` 0, `accuracy_pct` 100.0, `hits` note count, `misses` 0, `points` 0.0, `fail_time_ms` -1, `beatmap_hash` empty, `pitch_lock` false, `trailing_bytes` 0, `frames` at `fps` from 0 to the end (the later of last note plus `END_PAD_MS` and the audio end, but never beyond the audio end when it is known), `health` 1.0 everywhere.

Movement rules (from the spec, pinned):
- Gap `t` in real seconds = (note time difference in ms / 1000) / speed_mod. `d` = cursor-space distance. Target length `L = clamp(CRUISE * t, d, L_max)` with `L_max = 2 * bound * 1.5`.
- Same spot = `d < 2 * HITBOX_HALF * 0.25`. Hold when `t < 0.35`; Boomerang otherwise: reach `r = min(CRUISE * t / 2.2, room) * dance.factor()`, direction from the dice among the directions with room, out along one cubic and back along another with a perpendicular offset of `0.35 * r` so the two arcs differ.
- Otherwise a cubic Bezier from A to B whose control points sit at a third and two thirds of the chord, pushed perpendicular by `b = min((L - d) / 2, room) * dance.factor()` to the dice's side (or the side with more room when one side has none), with the arrival tangent continuing into the next segment's departure. Under `Movement::Normal` `b = 0` and the boomerang becomes a hold.
- Rest when `t >= settings.rest_secs`: RestOut from A to the centre over `min(1.0, t / 3)` s at cruise pace, Hold at the centre, RestIn leaving at `t1 - (distance_to_B / CRUISE)` seconds.
- Dense runs: when `L` equals `d` the curve is the straight chord (sharp turns are allowed).
- Clusters: notes within 1 ms of each other form a chord; the cursor visits them in chart order at `t_k + j * dt` with `dt = min(1000 / fps, window / count)` where `window` is `55 * speed_mod` ms, two adjacent notes (centres within `2 * HITBOX_HALF`) from one point inside both hit areas at the shared time; each note gets one `hit: true` frame nearest its visit time; isolated notes get the frame nearest their time.
- Every sampled position goes through `clamp` with `bound = grid + (0.5 - CURSOR_EDGE_INSET)` and `grid = max(1.0, max |world coordinate| over the notes)`; the room used for bulges is the distance from the chord's midpoint to the barrier on that side.
- The first segment starts at the centre at time 0; after the last note the cursor eases to the centre within 1.0 s.
